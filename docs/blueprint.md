# **App Name**: REACH: Nurture

## Core Features:

- User Authentication: Secure authentication using Firebase Auth for coordinators and reachers.
- Contact Collection: Collect contact information of new believers.
- Automated Follow-ups: Schedule and send automated follow-up messages and reminders.
- Dashboard: Display key metrics, follow-up completion rates, and team activity levels.
- Gamification: Encourage the leader and evangelists in the outreach program
- Discipleship Feed: Share devotionals with believers
- AI Encouragement: AI tool to provide personalized encouragements, that selects encouragement from scripture appropriate to the conversation and user profile.

## Style Guidelines:

- Primary color: Gold (#FFD700) to represent the divine and inspire trust.
- Background color: Off-white (#F8F8FF) to maintain a clean, friendly and approachable feel.
- Accent color: Blue (#87CEEB) for interactive elements and important notifications.
- Body and headline font: 'PT Sans', a modern yet friendly sans-serif for readability and warmth.
- Use clear, simple, and recognizable icons related to faith, community, and growth.
- Design a clean, simple, and mobile-first layout with large, clear buttons for ease of use.
- Use subtle transitions and animations to provide feedback and enhance the user experience.
